# Milestone 2 – Functional Scope

## Included
- Catalogue selection for the 7 priority connector groups.
- Create/list/status-change/delete connection profiles, tenant-scoped.
- Draft and disabled states.
- Metadata configuration for Excel/CSV, REST/SFTP and planned connectors.
- Secret-reference field only; no secret value accepted.
- Owner/Admin/Designer can create/update; Owner/Admin can delete.
- Connection test status fields and UI placeholders.

## Deferred
- Actual source connection testing and secret retrieval.
- File upload, file parsing and extraction execution.
- OAuth/token acquisition, SFTP handshake, warehouse connectivity.
- Worker deployment, schedules, object discovery, extraction, mapping and data publication.
- Full audit-write pipeline and approval workflow.
