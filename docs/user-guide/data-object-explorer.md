# Data Object Explorer – User Guide

The Explorer currently has two capabilities:

## Browse illustrative source objects
Use the search box to find demo objects by name, source or FP&A tag. Use the source filter to narrow the catalogue. The current catalogue is illustrative and should not be treated as live customer metadata.

## Profile a CSV file
Choose a CSV file up to 10 MB. The browser reads the file locally and displays row count, column count, inferred column types, blank values, distinct values, repeated values and sample values. The file is not uploaded.

XLSX, live connector discovery, persisted profile history and worker execution are planned follow-on capabilities.
